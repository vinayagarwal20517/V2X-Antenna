# V2X-Antenna
Award-winning (IEEE SPACE 2026 Best Paper) dual-CP ME-dipole antenna designed in Ansys HFSS for mm-Wave Ka-band V2X systems. Features an optimized multilayer Rogers 5880 stack-up delivering a wide 8.31 GHz impedance bandwidth (28.59-36.90 GHz) and 4.1 GHz axial ratio bandwidth to eliminate multi-path fading in high-mobility vehicular networks.
